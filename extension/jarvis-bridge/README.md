# J.A.R.V.I.S. Dynamic Island Chrome Bridge (Extension)

Ekstensi ini memungkinkan **Jarvis** mengendalikan tab di profil **Google Chrome utama** Anda secara langsung (membuka URL, berpindah tab, me-refresh, menutup tab, dan membaca isi halaman web aktif).

> **Catatan:** Tanpa ekstensi ini, Jarvis tetap berfungsi penuh secara otomatis menggunakan jendela **Jarvis Chrome (CDP)** miliknya sendiri.

## Cara Memasang di Google Chrome (Sekali Saja)
1. Buka Google Chrome dan ketik `chrome://extensions` di address bar, lalu tekan **Enter**.
2. Aktifkan sakelar **Developer mode** (Mode pengembang) di pojok kanan atas.
3. Klik tombol **Load unpacked** (Muat yang belum dikemas) di pojok kiri atas.
4. Pilih folder ini:
   `C:\Users\zaenal\.gemini\antigravity\scratch\dynamic-island\extension\jarvis-bridge`
5. Selesai! Ekstensi akan langsung terhubung otomatis ke Dynamic Island (`ws://127.0.0.1:47321`).
